# Nidelv IL – Støtt nytt kunstgress

Nidelv Idrettslag skal legge nytt kunstgress og trenger din støtte! 🏆⚽

## Om prosjektet

Denne nettsiden er laget for å hjelpe Nidelv IL med å samle inn midler til et nytt kunstgressdekke. Støtt laget ditt og bidra til bedre treningsforhold for alle spillerne!

## Slik støtter du

Hver "flis" koster **400 kr**. Kjøp en eller flere fliser og hjelp oss å nå målet!

## Teknologi

- HTML, CSS og JavaScript
- Enkel og tilgjengelig nettside

## Lokalt

```bash
# Åpne index.html i nettleseren
open index.html
```
